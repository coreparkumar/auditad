The code to perform the "Reset Advertising ID" functionality is located in the following files:

1. Business Logic / ViewModel
In 
AuditViewModel.kt
, the application manages the advertising ID state and handles the reset logic:

kotlin


    // --- 4. Account Janitor ---
    private val _advertisingId = MutableStateFlow("f71a0e10-90fb-40db-91b5-fa6b216ff2bc")
    val advertisingId: StateFlow<String> = _advertisingId.asStateFlow()
    private val _isResettingAdId = MutableStateFlow(false)
    val isResettingAdId: StateFlow<Boolean> = _isResettingAdId.asStateFlow()
    fun resetAdvertisingId() {
        _isResettingAdId.value = true
        viewModelScope.launch {
            delay(1200) // sleek cinematic audit simulation
            _advertisingId.value = UUID.randomUUID().toString()
            _isResettingAdId.value = false
        }
    }
2. User Interface / Composable Screen
In 
AccountJanitorScreen.kt
